== Record Structure

The record has two scopes:

Device Scope::
The following Semantics reference the device Concept:
+
* GUDID Device Concept
** Description Semantic(s)
** Identifier Semantic(s)
** Stated Definition(s)
* Device Company Semantic
* Indication for Use Semantic
* Predicate Device Semantic
* Regulatory Classification Semantic
* Test Performed Semantic(s)

Test Performed Scope::
There is a _Test Performed Semantic_ for each test performed by the device, unique at the Specimen/Analyte level.
Every Semantic in this scope references a test performed, therefore there will be one of each Semantic per test performed by the device as they are dependent on the test performed.
This device has *two* tests performed,
so it has two Results Description Semantics, two Limit Metrics Semantics, and so on.

.Indication for Use Semantic
[cols="2,2,5a,2",options="header"]
|===
| Data Element | Data Type | Value | Source

| Indication for Use
| String
| The Xpert Xpress CoV-2 plus test, performed on the GeneXpert Dx and GeneXpert Infinity Systems, is a rapid real-time RT-PCR test intended for the qualitative detection of SARS-CoV-2 RNA in nasopharyngeal and anterior nasal swab specimens collected from individuals with signs and symptoms of respiratory tract infection.
The Xpert Xpress CoV-2 plus test is intended for use as an aid in the diagnosis of COVID-19 if used in conjunction with other clinical, epidemiologic, and laboratory findings.
Positive results are indicative of the presence of SARS-CoV-2 RNA.
Positive results do not rule out bacterial infection or co-infection with other pathogens.
Negative results do not preclude SARS-CoV-2 infection.
The results of this test should not be used as the sole basis for diagnosis and patient management decisions.
