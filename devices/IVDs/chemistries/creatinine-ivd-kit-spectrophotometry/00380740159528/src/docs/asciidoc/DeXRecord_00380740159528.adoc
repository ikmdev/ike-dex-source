== Record Structure

The record has two scopes:

Device Scope::
The following Semantics reference the device Concept:
+
* GUDID Device Concept
** Description Semantic(s)
** Identifier Semantic(s)
** Stated Definition(s)
* Device Company Semantic
* Indication for Use Semantic
* Predicate Device Semantic
* Regulatory Classification Semantic
* Test Performed Semantic(s)

Test Performed Scope::
There is a _Test Performed Semantic_ for each test performed by the device, unique at the Specimen/Analyte level.
Every Semantic in this scope references a test performed.
This device has *three* tests performed,
so it has three Associated Devices Semantics and three Results Description Semantics.
Each test also has three Limit Metrics Semantics (limit of detection, limit of blank, and limit of quantitation) and one Measuring Range Semantic.
The serum and plasma tests each have six Population Reference Range Semantics and the urine test has four,
for a total of nine Limit Metrics Semantics, three Measuring Range Semantics, and sixteen Population Reference Range Semantics.
The plasma and urine tests each also have one Comment Semantic to note discrepancies found when gathering the device data.
